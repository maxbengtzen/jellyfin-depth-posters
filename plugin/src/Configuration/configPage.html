Depth Posters

Parallax and tilt on poster hover, driven by depth maps from the jellyfin-depth-posters service. Reload the web UI after saving.

Address of the service as seen from the Jellyfin server, e.g. http://jellyfin-depth-posters:8000
Needs ENABLE_LAYERS=true on the service. Falls back to the depth map otherwise.
How far the poster layers move. 0.04 is subtle, 0.08 is strong.
0 = far, 1 = near. The depth that stays still while the rest moves.
